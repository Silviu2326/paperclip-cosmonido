# Social Post Copy

Prepare copy that helps the intended audience understand the finished video and its next step.

## Workflow

1. Confirm the target platform, audience, desired action, and any character limit in the brief.
2. Search current company context for approved terminology, offers, and claims.
3. Lead with the viewer's problem or outcome. Match the video instead of introducing a different promise.
4. Write one concise caption and a clear call to action. Add only relevant tags if requested.
5. Check names, links, prices, dates, and performance claims against approved sources. Remove anything unsupported.
6. Hand off the final copy with the platform and intended placement.

Do not publish or schedule posts. Publishing is outside this skill and requires a separate authorized workflow.
