# Short Video Script

Write a production-ready script for a short-form video using the assignment acceptance criteria and relevant company context.

## Workflow

1. Read the assignment brief, audience, expected deliverable, and acceptance criteria.
2. Search company context for current offers, brand guidance, and required claims. Use only files that match the task scope and are still valid.
3. State one viewer and one useful outcome. If either is unclear, surface the gap before drafting.
4. Write a first-line hook, short spoken lines, visual beats, and a specific ending. Keep each beat easy to record or edit.
5. Check that every factual claim is supported by supplied context. Mark any claim that needs confirmation.
6. Hand off the script with duration target, aspect ratio, on-screen text, and any source-media requirements.

Do not invent customer results, product capabilities, prices, or guarantees. Keep the script within the approved assignment scope and budget.
