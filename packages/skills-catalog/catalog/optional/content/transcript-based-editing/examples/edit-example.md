# Transcript Editing Example

## Transcript excerpt

“So, um, first open the project… [pause 1.4s] then choose Share. You can invite the team from there.”

## Editing decision

- Remove the opening “So, um” if the cut still sounds natural.
- Shorten the 1.4 second pause while keeping a brief breath before “then”.
- Keep “You can invite the team from there” because it completes the instruction.
- Listen to the cut in context before submitting the render.
