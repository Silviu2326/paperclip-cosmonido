# OpenAI, Azure, and Google adapters

Implementation date: 2026-10-22. Source edits are confined to these three provider directories and their tests. No shared contracts, barrels, dependencies, or parallel core helpers were changed. All HTTP calls use `ProviderContext.fetch`; each provider owns its tiny HTTP helper. Cancellation and `timeoutMs` remain active through audio/JSON body reads and streaming reads. Streaming readers are canceled when the consumer exits early.

## OpenAI

- The requested three models and thirteen static voices are exposed. Descriptive gender/tags are best-effort. Empty voice languages mean multilingual; the model language list follows the published Whisper/TTS set. Only the six legacy voices advertise `tts-1`/`tts-1-hd` compatibility.
- `instructions` combines language, emotion, expressiveness, and `providerOptions.instructions` only for the `gpt-4o-mini-tts` family. Older models omit it even when passed through provider options. SSML is reduced to plain text; timestamps and cloning remain unsupported as requested.
- The current [Speech API guide](https://developers.openai.com/api/docs/guides/text-to-speech) marks these models deprecated, with shutdown on **2027-01-06**. They are retained to satisfy this integration's explicit scope. This adapter does not implement Realtime or the newer gated custom-voice APIs.
- [Mini TTS pricing](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts) is **$0.60/M input text tokens and $12/M output audio tokens**, not input characters. Its `$12/M characters` estimate is the requested rough budgeting heuristic, not a published character tariff. The legacy models use the requested $15/$30 character rates. All pricing notes are dated.
- PCM/WAV defaults to 24 kHz, 16-bit mono. Explicit unsupported rates, bit depths, stereo, and configurable bitrates fail with `unsupported`; there is no local transcoder. Compressed sample-rate requests are rejected because the endpoint offers no rate control.
- `ctx.baseUrl` overrides `credentials.baseUrl`; paths and query parameters are retained when appending `/audio/speech`. Organization, project, and idempotency headers are forwarded. A native Azure OpenAI endpoint that requires `api-key` instead of bearer authentication still needs a compatible gateway; this is not a second Azure OpenAI authentication adapter.

## Azure

- Models are routing/pricing families, not a REST body field. Explicit voice names are preserved. Without an explicit model, synthesis reports the family of the chosen voice; `defaultModel()` separately chooses HD for a conservative set of supported languages. The 30-voice fallback is not an exhaustive regional catalog. Live secondary locales, styles, roles, and other fields remain in `raw`.
- [REST Speech](https://learn.microsoft.com/azure/ai-services/speech-service/rest-text-to-speech) provides chunked audio but no word-boundary timestamps. `timestamps` is false; SDK/WebSocket support is outside this adapter.
- Generated SSML escapes text and attributes, supports phonemes/aliases, and maps speed/pitch/gain and named emotion. A normalized style value is mapped to Azure's 0.01–2 style degree. Exact style availability depends on the selected voice. Caller SSML is preserved, adding a voice when absent. Personal Voice uses `mstts:ttsembedding` with a speaker profile ID.
- MP3, RIFF PCM, raw PCM, Ogg Opus, mu-law, and A-law native format mappings are implemented. `AudioContainer` has no `webm`, so WebM cannot be represented without widening the read-only contract. Unsupported combinations fail locally. Azure prices are regional budgeting estimates, not account-specific quotes.
- Personal Voice is **best-effort and access-gated**, not professional Custom Neural Voice training. The requested API version `2024-02-01-preview` is retained; current Microsoft docs now show `2026-01-01`. This preview implementation needs live qualification on an eligible resource.
- Enrollment requires `consent.attested`, `language`, `providerOptions.companyName`, a separate `providerOptions.consentAudio: AudioInput`, and reference `samples`. Optional `voiceTalentName`, `projectId`, `consentId`, and `personalVoiceId` are supported. Stable caller IDs are recommended when resuming a partially completed enrollment.
- [Consent uploads](https://learn.microsoft.com/azure/ai-services/speech-service/personal-voice-create-consent) and [Personal Voice audio uploads](https://learn.microsoft.com/azure/ai-services/speech-service/personal-voice-create-voice) use multipart **POST**. The requested **PUT** variant is implemented for hosted assets: supply `consentAudioUrl` and `audios: { containerUrl, extensions, prefix? }`. Project creation uses PUT with `kind: PersonalVoice`.
- Consent is polled before voice creation (default 10 polls, 1 second apart; `pollAttempts`/`pollIntervalMs` override within bounds). Pending consent returns a non-retryable timeout with resource IDs; it does not launch training prematurely. A personal voice returns `training` until ready. Poll `getVoice()` on the returned voice ID/job ID within that provider instance, or use exported `getPersonalVoice(ctx, jobId, signal)` after restart. `personal-job:<id>` is a pending resource, never a synthesis speaker ID. A ready speaker is `personal:<speakerProfileId>`. The default embedding carrier is `en-US-DragonLatestNeural`, overrideable with `providerOptions.baseVoice`.

## Google

- `requiredCredentials: []` reflects the contract's inability to express **apiKey OR accessToken**. Network calls enforce one of them; OAuth wins when both exist. API keys use `X-Goog-Api-Key` and an optional `credentials.project` supplies `X-Goog-User-Project`. `GOOGLE_APPLICATION_CREDENTIALS`, service-account loading, and token refresh are out of scope. Static model inspection does not need credentials; a core credential-availability check that only reads `requiredCredentials` may over-report Google availability.
- [Gemini TTS](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts) uses `voice.modelName`, the short voice name, and `input.prompt`. Emotion/style and requested prosody become prompt guidance, whose effects are approximate. `providerOptions.prompt`, `markup`, and `input.prompt`/`input.markup` are supported. Gemini has no asserted character tariff.
- Traditional voice families use `audioConfig` rate/pitch/gain, sample rate, and effects profiles. SSML pronunciation is generated when requested; `providerOptions.sayAs` and `providerOptions.prosody` expose `<say-as>` and explicit `<prosody>` attributes. Caller SSML passes through. SSML/rate/pitch support varies by family; Gemini/Chirp SSML and Studio word-mark timestamps are rejected locally.
- Timestamps use beta `enableTimePointing: ["SSML_MARK"]`. Plain text receives `w0`, `w1`, etc. plus an ending mark. Only returned points produce timestamps; the next point sets each end. If the last point has no successor, RIFF duration is used when available, otherwise its end equals its start. Caller-supplied mark names become timestamp labels because the contract has no mark-to-word map. Multi-word pronunciation substitutions combined with automatic word marks require caller-marked SSML.
- [Instant Custom Voice](https://docs.cloud.google.com/text-to-speech/docs/chirp3-instant-custom-voice) is allowlist-gated. It requires `consent.attested`, the exact provider consent script in `consent.text`, `language`, one reference `samples[0]`, and separate `providerOptions.consentAudio: AudioInput`. The request uses `referenceAudio`, **`voiceTalentConsent`**, `consentScript`, and `languageCode`. Returned `clone:<key>` IDs are routed to beta synthesis with `voice.voiceClone.voiceCloningKey`; treat these IDs as private voice material. There is no provider-side listing endpoint for these locally retained keys.
- Streaming is sequential sentence REST synthesis, not native bidi gRPC. Each yielded chunk is a complete encoded file; WAV/Ogg chunks must be decoded or remuxed before concatenation. Timestamp offsets are local to each chunk. Caller SSML/markup stays one request to avoid breaking syntax. Very long individual sentences still need caller/core chunking. Traditional TTS limits are measured in UTF-8 bytes, so the contract's advisory character limit is not a guarantee for multibyte text or SSML.
- PCM is raw; LINEAR16 is WAV. Google mu-law/A-law responses also include a WAV header, so their MIME is `audio/wav` while `format.container` retains the requested codec label. No local resampling/transcoding is performed.

## Catalogs and verification

Azure returns the static catalog without credentials. Google requires credentials for its network catalog call. Both fall back on transient catalog unavailability/timeouts, logging a warning when a logger exists; authentication/rate-limit errors are preserved. Google supplements live catalogs with the seven requested Gemini voices when absent.

Synthesis returns character usage and estimated cents where known. `SynthesisChunk` cannot carry usage under the existing contract, so streaming does not fabricate a usage event. No real credentials, billable synthesis, or live cloning were used. Fake-fetch tests exercise wire payloads, SSML/escaping, format mapping, catalog normalization/fallback, decoding, timestamps, cloning, streaming, errors, cancellation, and response-body deadlines.
