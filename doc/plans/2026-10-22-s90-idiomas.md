# S90 UI translations

The S90 translation addition is in `ui/src/i18n/s90-messages.ts`. It supplies typed English, Spanish and Portuguese
trees for contact import, customer/public review, daily brief preferences, opportunity forecast, package resource
installation, and the product-account usage notice. The Portuguese tree follows the English reference shape. The
existing S4 dictionaries are preserved and recursively merged with only missing S90 leaves in
`productization-messages.ts`; the existing locale-file merge remains additive, so an established locale-file message
is not overwritten. `locales.ts` did not need changes.

Coverage is limited to actual S90 `t()` / `tr()` calls observed in `ContactImport`, `ExternalReview`, `PublicReview`,
`DailyBriefPreferences`, `OpportunityForecastPanel`, and the resource parts of `PackageInstallPanel`, plus the
account-limit notice key. The `crm.phone` and product-billing status keys are prepared for the same UI batch but are
not currently called by a component. Existing static text in `ProductAccounts.tsx` and `ProductBilling.tsx` is outside
this ownership and remains untranslated; these keys alone do not localize that UI. Other shipped locales receive the
existing English fallback for these additions, as they do for S4 additions. This is not a claim of complete
repository-wide locale coverage.

No UI components or design tokens changed. Tests, checks, typecheck, build, generators and providers were not run under
the task constraints.
