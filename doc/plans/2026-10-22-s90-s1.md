## Tool catalog finding

`assignmentToolDefinitions()` and `mediaToolDefinitions()` use the server shim's `CAPABILITY_SEMANTIC_TOOL_CATALOG`. The shim re-exports the package entrypoint's live catalog from `semantic-tools/index.ts` / `semantic-tools/catalog.ts`, which includes protocol actions where `live !== null`, including `assignment-context-media.ts` actions. Their `scenario: null` field only excludes them from the separate eval/scenario projection in `tools/capability-semantic-tool-catalog.ts`. In particular, `get_assignment` and `submit_deliverable_for_review` have live definitions and `standard` mode, and media actions have live definitions/modes. Thus `assignmentToolDefinitions("standard")` is not empty because of `scenario: null`; no catalog change is warranted. If a consumer needs the scenario-only projection, it must use that explicitly named tools catalog, never substitute it for live tool definitions.
