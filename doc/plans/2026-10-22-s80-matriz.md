# Auditoría de alcance S4 A–N y cuentas/API

Actualización del integrador: el banco S3 sin adaptadores reales devuelve ahora 422 antes de crear una ejecución. Las referencias a la llamada desde el constructor describen el punto de integración, no un banco utilizable ni una evaluación ejecutada. Una nota heurística o menos de 20 casos no habilita subir autonomía. Véase [estado transversal](2026-10-22-sprints-80.md).

Fecha de corte: 2026-10-22. Fuente de contrato: [Sprint 4, plan maestro](2026-10-21-plan-maestro-producto.md), tabla “Pistas en paralelo”, A–N; para límites comerciales, [contrato de cuentas](2026-10-22-s80-cuentas.md) y [contrato plan-gate](2026-10-22-s4-plan-gate.md). Alcance de esta auditoría: evidencia en el código fuente y rutas que se pueden inspeccionar en este worktree. No se ejecutaron pruebas, typecheck, builds, checks, migraciones ni recorridos reales; por tanto, ninguna fila acredita aceptación en ejecución.

Estados: **Completo en fuente** = el criterio descrito tiene implementación visible; **Parcial** = sólo una parte o sustituto explícitamente limitado; **Falta** = no se encontró implementación para el criterio; **Configuración externa** = el código espera configuración/transportes/credenciales externas; **No verificado** = la evidencia es estática y su funcionamiento no se comprobó en ejecución. Se combinan cuando corresponde.
